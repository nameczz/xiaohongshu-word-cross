# 单词纵横

一个面向英语学习者的离线纵横填词小游戏，为小红书 H5 小工具容器设计。

## 功能

- 10 个主题、400 条本地英文词汇
- 7×7 至 9×9 随机交叉棋盘
- 简单、普通、困难三档预填比例
- 手机系统键盘直接填写，一格一个字母
- 英文线索与中文分级提示
- 自动存档、计时、星级和成绩卡
- 小红书 JSBridge 保存成绩卡与发布笔记
- 纯离线运行，不使用网络请求或外部依赖

## 本地运行

直接在浏览器打开 `index.html` 即可：

```bash
open index.html
```

## 测试

项目使用 Node.js 内置测试工具，无需安装依赖：

```bash
node --test tests/generator.test.js
```

测试覆盖词库结构、600 个随机棋盘、同种子确定性、棋盘结构校验和异常输入。

## 小红书小工具约束

页面使用经典外置脚本和相对资源路径，所有数据均打包在本地。正式上传时需将 `index.html` 与 `app/` 目录一起压缩，并确保 `index.html` 位于 ZIP 根目录。
